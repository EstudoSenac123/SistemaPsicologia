## 🎯 Objetivo do software

O Sistema de Agendamento Psicológico tem como objetivo facilitar o cadastro de pacientes e psicólogos e permitir o agendamento e a consulta de atendimentos psicológicos.

O sistema foi desenvolvido como parte do Projeto Integrador (PI), utilizando uma aplicação desktop em Java integrada a um banco de dados MySQL.

## ⚙️ Funcionalidades do sistema

- Cadastro de pacientes;
- Cadastro de psicólogos;
- Login de usuários;
- Agendamento de consultas;
- Consulta de consultas agendadas;
- Visualização dos dados dos usuários;
- Integração com banco de dados MySQL;
- Navegação entre as telas do sistema.

## 🗄️ Banco de dados

O sistema utiliza o **MySQL** para armazenamento dos dados de pacientes, psicólogos, usuários e consultas.

## 📂 Projeto

O projeto foi desenvolvido utilizando o **Java** no ambiente **Apache NetBeans**, com gerenciamento do projeto através do **Maven**.

## 🔄 Versionamento

O projeto utiliza **Git e GitHub** para controle de versões, permitindo acompanhar as alterações realizadas no código e manter uma cópia remota do projeto.
